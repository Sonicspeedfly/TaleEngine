# Волна 3: Оболочка «Рукописи», поиск и навигация — план реализации

**Цель:** продукт перестаёт терять собственное содержимое. Появляется один список
всех чатов, поиск по репликам, командная палитра и ветвление, а шапка и композер
перестают спорить за внимание.

**Подход:** три новых эндпоинта на бэкенде (имя персонажа в списке, поиск, форк),
единый список чатов на клиенте, палитра как отдельный оверлей, и замена трёх
конфликтующих булевых флагов композера одним селективным состоянием.

**Ограничения:** без сборки и зависимостей. WebSocket/SSE, `_handoffStreaming`,
`resumeSSE`, сторож стриминга и `onWsEvent` не трогаются. Откат — ветка
`wave3-shell-search`, копии в `C:/Temp/claude/w3-*`.

**Спека:** отчёт «Редизайн TaleEngine», волна 3.

## Глобальные ограничения

- Поиск обязан уважать права: пользователь видит только свои чаты и те, которыми
  с ним поделились. Опираемся на существующие `accounts.scope_query` и `SessionShare`.
- Форк копирует историю ДО выбранной реплики включительно и не трогает исходный чат.
- Одно поле режима вместо трёх флагов: расхождение надписи на кнопке отправки и
  реального действия должно стать невозможным по устройству, а не по дисциплине.
- Палитра — модальный слой, поэтому попадает в существующую ловушку фокуса и
  цепочку Esc из волны 2.
